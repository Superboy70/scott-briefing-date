# 부품함 정리 — 기획 1장

v0.1 · 2026-10-27 · **Scott 승인 대기** (DEV_PLAYBOOK 0단계)

같은 색띠 저항을 한 칸에 4개씩 모으는 정렬 퍼즐. 2026년 상반기 캐주얼 매출에서 퍼즐이 44%를 차지하고, 정렬·블록류 하이브리드 퍼즐이 +46%로 가장 빠르게 큰다(AppMagic H1 2026). 마계 성전(미드코어 액션)과는 시장도 검증 방식도 다르게 간다.

## 재미 정의 — 모든 기능·수치 변경은 여기에 비춰 판단

- **가설**: 뒤엉킨 부품함을 몇 수 앞까지 읽고 풀어낼 때, 칸이 하나씩 딱 정리되는 쾌감이 즐겁다.
- **기둥**: ① 수 읽기(계획) ② 정리 손맛(소리·진동·완료 표시등) ③ 짧은 성취 반복(한 판 1~3분). 셋 중 어디에도 안 걸리는 기능은 만들지 않는다.
- **반목표**: 풀 수 없는 판 · 생각 없이 풀리는 고비 레벨 · 흐름을 끊는 광고 · 힌트 없이는 못 깨는 판.

## 목표 숫자 — 봇으로 잰다 (`tools/curve.js`와 같게 유지)

| 지표 | 재는 방법 | 목표 |
|---|---|---|
| 풀 수 있음 | 해결기(A*)가 최소 수를 찾음 | 100% |
| 생각이 필요한 정도 | 초보 봇(앞을 안 보고 두는 봇) 200판 해결률 | 도입(1~5) 80~100% · 일반(6~19) 30~80% · 후반(21~29) 10~40% · 고비(10·15·20·25·30) ≤15% |
| 톱니 곡선 | 고비 다음 레벨의 초보 해결률 > 고비 | 전부 |
| 첫인상 | 1레벨 최소 수 | ≤10수 |
| 손맛·체감 | 사람만 확인 | 큰 변경 때 Scott 5분 플레이 |
| 별 3개 비율 | 출시 후 플레이 로그 | 레벨당 20~50% |

v0.1 측정값: 30레벨 모두 목표 구간 안, 톱니 4/4, 1레벨 10수 (`tools/results.csv`).

## 수익 (가설, 출시 후 검증)
