# 마계 성전 (Demon Crusade)

디아블로 2의 **파밍·성장 시스템**과 마계촌의 **투척 무기 횡스크롤 액션**을 합친 1인용 모바일 게임입니다.
Android 13~16용 APK(Capacitor 8, minSdk 24 / targetSdk 36)로 빌드되고, 웹 브라우저(PWA)에서도 실행됩니다.

## 게임 구성

| 요소 | 출처 | 내용 |
|---|---|---|
| 투척 무기 | 마계촌 | 창·단검·도끼(포물선, 관통)·횃불(바닥 화염)·마법구(유도). 화면에 나가 있는 투사체 수 제한 |
| 갑옷 파괴 | 마계촌 | 갑옷 내구도가 먼저 피해를 받고, 0이 되면 갑옷이 부서져 하트 팬티 차림이 됨 |
| 좀비 출현 / 붉은 악마 / 보물상자 마법사 | 마계촌 | 땅에서 좀비가 계속 올라오고, 급강하하며 투사체를 피하는 악마가 나옴. 보물상자를 열면 가끔 오리로 변하는 저주 |
| 2회차 엔딩 | 마계촌 | 노말 엔딩은 "함정". 나이트메어 → 헬을 깨야 진짜 엔딩 |
| 3직업 · 스킬 | 디아블로 2 | 성기사(심판의 일격/신성 방패), 소서리스(서리 구체/순간이동), 네크로맨서(해골 소환/뼈 창) |
| 아이템 등급 | 디아블로 2 | 일반/마법/희귀/고유 등급, 옵션 25종, 고유 아이템 18종, 몬스터 레벨 기반 드롭 |
| 정예 몬스터 | 디아블로 2 | 챔피언(파란색), 고유 몬스터(금색 이름 + 속성: 빠름/극도로 강함/돌 피부/화염·냉기 강화) |
| 마을 | 디아블로 2 | 웨이포인트, 상인(물약·장비), 대장장이(갑옷 수리), 도박꾼, 레벨업 시 능력치/스킬 포인트 |
| 성소 | 디아블로 2 | 회복·강철·경험·전투 성소 |

4막 × 3지역 = 12개 지역이 있고, 각 막의 마지막 지역에는 보스(무덤군주 → 거미 여왕 → 화염마왕 → 공포의 군주)가 나옵니다. 지형은 입장할 때마다 새로 생성됩니다.

## APK 받기 (권장)

`demon-crusade/` 폴더에 푸시할 때마다 GitHub Actions(`Build Demon Crusade APK`)가 APK를 자동으로 빌드합니다.

1. 저장소 **Releases** → `demon-crusade-latest`에서 `demon-crusade.apk`를 휴대폰으로 받습니다.
   (Actions 실행 결과의 Artifacts에서도 받을 수 있습니다.)
2. 설치할 때 "출처를 알 수 없는 앱 설치"를 허용합니다.
   디버그 서명 APK이므로 Play 프로텍트 경고가 나오면 "무시하고 설치"를 누르세요.

## 로컬 개발

```bash
cd demon-crusade
npm install
npm run serve                 # http://localhost:8080 에서 웹으로 플레이
npm run android:init          # android/ 프로젝트 생성 + 가로모드·전체화면·아이콘 패치
npx cap sync android && npm run android:build   # Android SDK 필요
```

- 게임 코드: `www/js/` (data, items, world, entities, render, ui, main)
- 아이콘 재생성: `node assets/make-icons.mjs` (Playwright 필요)

## Android 13~16 대응 사항

- targetSdk 36 (Android 16), minSdk 24
- 가로 고정(`sensorLandscape`), 몰입형 전체화면(시스템 바 숨김), 화면 꺼짐 방지
- Android 15 이상에서 강제되는 edge-to-edge 및 카메라 컷아웃: HUD와 버튼이 safe-area 여백을 피해서 배치됨
- 뒤로가기 제스처: 플레이 중에는 일시정지, 메뉴에서는 이전 화면, 타이틀에서는 앱 종료
- 앱이 백그라운드로 가면 자동으로 일시정지하고 저장(localStorage)
